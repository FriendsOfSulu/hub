Extends Sulu articles with a Configuration tab for layout styles, sidebars, element visibility, share and print controls, and custom CSS classes. Settings resolve through article overrides, template defaults and built-in defaults, with Twig functions exposing the resolved values to website templates. Projects can add, change or remove fields through Sulu form XML per article group or template without database schema changes.
