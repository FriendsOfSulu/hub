Generates PDF downloads by extracting content from rendered public pages, articles and events, reusing existing block templates. Resource profiles and CSS selectors control content extraction, while a customizable PDF layout provides logos, brand colors, fonts, page numbers and QR codes. Optional excerpt fields let editors control PDF availability and display options per locale through Sulu's draft and publish workflow.
